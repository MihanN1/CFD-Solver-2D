# Current State

## 2026-08-21 17:35

Status:
- Written
- Tested

Project boundary:
- UI is a standalone CMake project.
- `CFD-Solver-2D` was inspected only as the authoritative release-matrix/runtime-contract reference.
- No Fluid Solver source, binary, or published solver archive was modified.

Current fresh-run integration:
- 24 solver keys are generated by `FluidSolverRun`.
- Gravity keys are not emitted.
- Restart/continuation keys are not emitted.
- A fresh UI defaults to `./output` relative to the process working directory.
- The UI creates timestamped run folders there and passes the resulting absolute path as solver `outputDir`.
- Saved UI preferences or a loaded `.cfdui` file can override that default.

Release/build state:
- `CFD_UI_STATIC_RUNTIME=ON` by default.
- SFML + bundled FreeType/HarfBuzz/SheenBidi are static.
- Windows uses static MSVC CRT.
- Linux/GCC uses static libgcc/libstdc++; X11/OpenGL remain OS dependencies.
- macOS keeps required system runtimes/frameworks dynamic.
- `CFD_UI_ENABLE_AVX2` produces an actual AVX2 UI binary.
- `scripts/build-ui-release.py` defines the exact 30 solver-corresponding `*-ui.zip` names.
- OpenMP/CUDA feature suffixes are package/installer pairing identities because the UI does not execute OpenMP/CUDA solver kernels.
- `.github/workflows/build-ui-all.yml` builds Windows, Linux, macOS arm64, and macOS x64 rows on native runners and finalizes one checked release.
- Built executable name is `Fluid Solver UI[.exe]`.
